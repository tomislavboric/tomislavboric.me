Selected work

Four projects that show how I work: one I own end to end, one for a client, one inside a product team, and one small thing I built for my friends.

Own product Deployed, pilot stage 2025 – 2026

Camppy — campsite operations SaaS

Turns imported bookings into cleaning schedules and a clear day of work for field teams, with role-based views for managers, cleaners and unit owners.

I designed and built the whole thing: the data model and row-level security in Postgres, the booking import from Booking.com and Airbnb calendars, a scheduling board where changes are planned first and saved as one batch, an offline queue for phones with bad reception, and a twelve-language interface. It runs as a PWA so cleaners use it from their pocket.

Role
Founder, designer, developer
Stack
Vue 3, Pinia, Supabase (Postgres, RLS, Realtime), Vercel functions, PWA, Vitest
Client Pre-launch 2026

Move by Erika — headless fitness membership platform

A Next.js front end over WordPress content, with Supabase accounts and Stripe subscriptions for an online training studio. Editors keep Gutenberg; members get a paid video library and a seven-step nutrition questionnaire validated on both client and server. Next and WordPress talk through signed requests, so there is no shared login to leak.

Role
Sole developer, through my studio inWeb
Stack
Next.js 16, React 19, WPGraphQL, custom WP plugins, Supabase Auth, Stripe, Vercel

About

I started in 2009 as a freelancer, building websites for small businesses in Zagreb. In 2015 that became inWeb, my own studio, and a long run of WordPress builds: themes from scratch, WooCommerce shops, membership sites, page builders editors could actually use.

In 2020 I joined Sched, a SaaS for event organisers, first on the marketing site and growth experiments, then in the product team working on the control panel. That is where marketing-site habits turned into product habits: states, roles, edge cases, and the patience to make a legacy codebase a little better with every change.

Camppy is what I do with that experience when nobody hands me a spec. I designed the product, built it and run it. It taught me more about data modelling, security rules and operations than any client project could.

I use AI tools every day and say so. The architecture, the decisions and the bugs are still mine.
